# assets/

- **euverify-icon.png**, **euverify-wordmark.png**, **euverify-wordmark-white.png**: Euverify logos with the background removed. `logos.js` holds the same images as embedded data so the game also works offline.
- The world map in `worldmap.js` is simplified from Natural Earth country outlines (public domain, via the world-atlas package).
- Everything else (hero, enemies, cities, landmarks, flags, map animation) is drawn in code in `script.js`, and all music and sound effects are synthesised with the Web Audio API.
